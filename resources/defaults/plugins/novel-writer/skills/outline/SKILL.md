# Outline Novel

Use this skill specifically for the **pre-drafting phase**: premise development, plot structuring, character creation, worldbuilding, and chapter-by-chapter outlining. Does not produce full chapter drafts.

## Workflow

1. **Premise Workshop** — refine the core idea, genre, tone, and central conflict.
2. **Character Creation** — protagonist, antagonist, supporting cast with motivations and arcs.
3. **Plot Architecture** — three-act structure, act breaks, subplots, setup-payoff pairs.
4. **Chapter Outline** — one-paragraph summary per chapter, with POV, threads, and word count targets.
5. **Write novel.json** — save structured outline to `novel.json`.

## Output

- A populated `novel.json` manifest with outline, characters, plot threads, and settings.
- Status set to `outline`.
- User can then switch to `plugin:novel-writer/write-novel` for drafting.
